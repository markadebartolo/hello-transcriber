# Hello Transcriber

A standalone macOS menu bar dictation app, extracted from Mark DeBartolo’s Dorsal.

Status: release preparation. No validated binary release yet.

Build without signing or launching: `bash hello/scripts/check.sh`.
Requires macOS 14.2 or later and Xcode. No packages, sibling checkout, or API keys.
